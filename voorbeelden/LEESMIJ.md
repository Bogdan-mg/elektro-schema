# Voorbeelden

Zet hier PDF's of afbeeldingen die Claude moet bekijken, bijvoorbeeld:

- projecten uit Trikker (ééndraadschema, situatieschema),
- plannen van de architect,
- symbolenlijsten of andere voorbeelden.

Uploaden kan op GitHub via **Add file → Upload files**. Zeg daarna in het gesprek welk bestand het is.

Deze map wordt niet in het programma of de installer opgenomen.

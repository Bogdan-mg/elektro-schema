# Elektro Schema

Windows-programma om **ééndraadschema's**, **situatieschema's** en **materiaallijsten** te tekenen voor elektrische installaties (België, AREI). Volledig offline.

> In opbouw. De kern (model, AREI-controle, materiaallijst) staat er al, met tests. De schermen volgen.
